词库制作工具

可逐条填写，也可粘贴 CSV。导入时会先用站内词库补齐空白字段；站内没有的词再尝试 Jisho.org 免费词典。

字段含义示例
w词形，唯一必填项図書館
r假名读音としょかん
pos词性名詞
cn中文意思图书馆
en英文意思library
category分类；同名自动归组学校・学习
ex日语例句図書館で本を借ります。
exCn例句中文翻译在图书馆借书。

接入网站

JSON 适合保存和继续编辑。下载 JS 后放入 data/，在页面引入该文件，再在 app.js 的 BOOKS 中增加一项，令 vocab 指向 window.CUSTOM_VOCAB。每个词条的 category 值会成为分类选项。
