# NihongoLab

NihongoLab 是一个可直接部署到静态服务器的日语学习网站，包含 JLPT N5 至 N1 与 EJU 的词汇、语法和阅读练习。

## 内容

| 词库 | 条数 |
| --- | ---: |
| EJU 综合词汇 | 3,200 |
| JLPT N5 基础词汇 | 118 |
| JLPT N4 基础词汇 | 177 |
| JLPT N4 扩展词汇 | 662 |
| JLPT N3 基础词汇 | 187 |
| JLPT N2 综合词汇 | 3,434 |
| JLPT N1 基础词汇 | 147 |

词汇数据保留词形、读音、词性和中英文释义等通用词典信息。

语法模块现有 758 个语法点，按 N5 至 N1 与 EJU 分类；每个语法点配有 3 组日中例句，共 2,274 组。阅读模块现有 120 篇短文与 240 道日文选择题，答案与解析在提交后显示，中文译文默认折叠。

## 功能

- 按词库、类别、词性和序号范围筛选。
- 假名与汉字互答、选择题、中文释义题、听写和听音选义。
- 查看词表并导出 Excel 练习或词表。
- 用浏览器本地存储保存学习进度。
- 保存考试成绩、学习流水和每个词的答题历史。
- 按等级浏览语法和阅读内容。
- 支持系统夜间模式和手动切换。

朗读功能调用浏览器和操作系统提供的 `SpeechSynthesis` 日语语音，实际音色与可用性取决于用户设备。

## 使用与部署

直接打开 `index.html` 即可使用。部署时将整个目录上传到任意静态网站服务：

```text
NihongoLab/
├── index.html
├── app.js
├── xlsx.js
├── assets/
├── data/
├── grammar/
├── reading/
└── thanks/
```

所有页面和数据都使用相对路径，不需要后端服务。
